# all the features of this project

### read:
this script can allow users to read data based on the data title, or alternatively use the ID. using ID to search is marginally faster than Title search as it skips the title to ID translation, however it is heavily not recommended as future features and optimisations will mean the ID can be changed.

### write:
this script can also allow users and scripts to write and update data to the storage drive, and to allow for other scripts to then read the data. the paramaters are the value, the title of the data being stored, priority and overwrite

- **value**: the data that should be stored. it could be any thing
- **title**: the title that other scripts search the data by. Please use a recognisable and memorable title so that you won't forget this
- **priority**: if you want the data to be stored as priority or not. currently this only means that the data will be stored in ID 1-100, and non-priority data will be stored from ID 101. if no value is imputted the script will default the priority to non-priority
- **overwrite**: this is a boolean toggle. this toggle will only prevent overwrite of data with the same title if this option is specifically `false`. any other value or the lack of a value will default to overwriting data

## speed
#### write:
- average execution time: 2s
- max rate of use: 60 write / minute (aka. not relavent)

#### read:
- average execution time: 1.5s
- max rate of use: 60 read / minute
